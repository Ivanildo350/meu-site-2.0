Bem-vindo ao website do Instituto Industrial e Comercial de Nampula. Neste curso aprendemos HTML, a linguagem usada para criar a estrutura das páginas Web: títulos, parágrafos, imagens, links e tabelas.

O CSS permite dar cor, tamanho e estilo às páginas. Ao usar um ficheiro CSS externo, formatamos várias páginas ao mesmo tempo, mantendo o código organizado.
